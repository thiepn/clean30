# Clean30 Tester Guide

Thanks for testing Clean30.

Clean30 is a local-first apartment cleaning routine app. It helps with Daily Rules, custom dashboard tasks, reset sessions, cleaning systems, routines, history, and backups.

Live app: https://thiepn.github.io/clean30/

Recommended device: phone. Desktop testing is also useful.

## What To Test

- First launch and onboarding.
- Dashboard: Daily Rules, custom to-dos, routine starting, and active sessions.
- Routines: can you inspect routine checklists without feeling pushed to start?
- History: are Daily Rules and reset sessions understandable?
- Settings: do systems, backup, appearance, privacy, help, install, and reset tools make sense?
- Internal editor: can you edit Daily Rules or routines from Dashboard when using an editable template?
- PWA install: can you add it to your phone home screen?

## Feedback Questions

- Was onboarding clear?
- Could you tell what to do from Dashboard?
- Were Daily Rules useful?
- Did the custom to-do list make sense?
- Was starting, pausing, finishing, or discarding a session clear?
- Was the Routines tab useful as a reference library?
- Did backup/privacy make sense?
- What confused you?
- Would you use this weekly?
- What felt unnecessary?

## Local-Only Data Note

Clean30 has no account, no cloud sync, no analytics, and no ads. Your data stays in your browser or installed PWA storage.

If you care about the test data you create, export a full backup from Settings. Clearing browser/app data may delete Clean30 data.
